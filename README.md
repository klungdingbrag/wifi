# Nusantara WiFi V1

Frontend GitHub Pages + Google Apps Script + Google Sheets.

## Struktur
- `frontend/` — aplikasi web Vanilla JS.
- `backend/` — source Google Apps Script production.
- `docs/` — dokumentasi arsitektur, API, dan deployment.

## Development
Aplikasi frontend tidak memakai framework atau build step.
Backend tetap terpisah dan database production tidak dipindahkan ke repository frontend.

## Production
- Frontend: GitHub Pages
- Backend: Google Apps Script Web App
- Database: Google Sheets
